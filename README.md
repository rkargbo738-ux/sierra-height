# SIERRA HEIGHTS - Premium Student Accommodation

**WHERE AMBITION MEETS ELEGANT LIVING**

Sierra Heights is a premium student accommodation platform for students in Freetown, Sierra Leone. Providing modern, secure, and comfortable housing near universities.

### 🌍 Locations
- Hill Station Residence (Near Fourah Bay College)
- Aberdeen Premium Suites (Ocean View)
- Wilberforce Student Lofts (Affordable Luxury)

### ✨ Features
- 5 Separate Pages: Home, Our Services, Amenities, Contact Us, Registration
- Reservation System with Booking Form
- Responsive Design
- Font: Tahoma (Assignment Requirement)
- Color Theme: Deep Forest Green (#12372a) & Gold (#e8c05a)

### 🛠️ Technologies Used
- HTML5
- CSS3 (Inline & Internal - No External Framework)
- JavaScript (Form Validation)
- Git & GitHub for Collaboration
